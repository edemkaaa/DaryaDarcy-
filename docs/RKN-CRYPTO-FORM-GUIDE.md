## Рекомендуемое заполнение для ИСПДн daryadarcy.com

### Блок «Использование шифровальных (криптографических) средств»

**Используются:** Да (защищённый канал HTTPS при передаче данных пользователей).

**Наименование средства шифрования (текстовое поле):**

```
OpenSSL 3.0.13; протокол TLS 1.2/1.3; веб-сервер nginx 1.24.0;
сертификат TLS Let's Encrypt (ISRG Root X1) для домена daryadarcy.com
```

**Изготовитель:**

```
OpenSSL Project (библиотека OpenSSL);
Let's Encrypt / Internet Security Research Group (сертификат TLS)
```

**Серийный номер / регистрационный номер:**

```
Не применяется (программное обеспечение общего назначения, не сертифицированное СКЗИ)
```

**Класс средств криптографической защиты информации (КЗИ):**

```
Не применяется — используются несертифицированные средства криптографической защиты
для обеспечения HTTPS (TLS), без применения сертифицированных СКЗИ по приказам ФСБ
```

Если в форме есть выпадающий список классов КЗИ — выбирать вариант вроде **«не используются сертифицированные СКЗИ»** / **«иное»** с пояснением в текстовом поле (зависит от актуальной версии формы — **зафиксировать скрином**).

Если ИП подписывает форму **квалифицированной ЭЦП** через КриптоПро на своём компьютере:

- Это **не** часть информационной системы daryadarcy.com
- В разделе про ИСПДн указывать OpenSSL/TLS (см. выше)
- ЭЦП КриптоПро можно упомянуть только если РКН требует в том же блоке — тогда отдельной строкой: «КриптоПро CSP — для подписи документов оператора, не для обработки ПДн в приложении»
