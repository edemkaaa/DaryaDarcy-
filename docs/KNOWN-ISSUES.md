# Известные ограничения, баги и технический долг

Обновлено: август 2026.

## Недавно исправлено

- Тексты постов Instagram пустые после миграции → backfill из JSON
- Emoji в ленте отображались как `??` → utf8mb4 + системный шрифт для emoji
- Photo viewer: «склеенные» фото, нет свайпа → ScrollView paging
- Rich text: ссылки на неправильное слово, multi-word selection → selection fixes

## Открытые / частичные

| Область | Описание | Приоритет |
|---------|----------|-----------|
| **Staging** | Нет отдельного тестового домена | Средний |
| **Git remote** | Репозиторий локальный, remote не настроен | Средний |
| **Instagram sync** | Нет live-синхронизации; импорт через JSON/скрипты | Низкий |
| **Shop checkout** | UI есть, полная интеграция оплаты книг — уточнить | Средний |
| **Pen pals PII** | Адреса в БД; нужна политика retention | Средний |
| **Push notifications** | Регистрация токенов есть, массовая рассылка — базовая | Низкий |
| **E2E tests** | Нет Playwright/Detox; только unit/regression Vitest | Средний |
| **i18n** | Интерфейс на русском, без полной локализации | Низкий |
| **Offline PWA** | Service worker базовый, не full offline | Низкий |

## Технический долг

- Много одноразовых `scripts/_probe-*.mjs` — можно заархивировать
- `drizzle/` — смешение SQL-файлов и schema.ts; миграции не автоматизированы в CI
- Admin rich text editor — сложная связка native selection + web
- Дублирование логики feed/club в UI-компонентах

## Рекомендации для аудита

1. UX flow регистрации → клуб → контент
2. Доступность (a11y) на web/PWA
3. Безопасность admin routes и upload
4. Консистентность типографики (EB Garamond vs emoji/system fonts)
5. Edge cases подписки (истечение, повторная оплата)
