## Обновление от 4 ноября

Подготовленный ранее пакет не содержит последующего исправления обработки запросов после удаления аккаунта. Исправление сохранено в коммите `b6c8d6cd`. Пакет `../.local-artifacts/retirement-fix-20261104/candidate-b6c8d6cd.bundle` проверен командой git bundle verify относительно локальной базы `61e42ef2`. Сборка образа ARM64 остановилась до приёмки: при 116 МиБ свободного места Docker сообщил об ошибке записи метаданных BuildKit (read-only file system). После освобождения места проверить возможность записи Docker, повторить сборку и HTTP-проверки. [Отчёт](../audits/late-content-mutation-review-2026-11-04.md).

Владелец разрешил обновить актуальную объединённую версию. Выпуск пока не
выполнен: GitLab не завершает HTTPS/fetch, SSH155.212.216.16 останавливается
до авторизации (banner timeout). Обычный fetch и отдельная проба HTTP/1.1
не завершились. Daryadarcy/Mini также не ответили по HTTPS. DNS на Mac уже
возвращает адреса; причина оставшейся сетевой недоступности/VPS не установлена.
Настройки сети/DNS не менялись. После сообщения об отказе владелец подтвердил,
что доступ, вероятно, ещё не восстановлен. Рабочие ресурсы не изменялись.

## Точный остаток для реального обновления

1. Восстановить соединение с git.reeskeen.ru и SSH целевого сервера. Получить
   свежий staging, просмотреть входящие коммиты и объединить их без force push.
2. После merge проверить затронутые части, source SHA и публичный build profile.
3. Снять текущие private Compose/image pins/flags, ресурсы и историю БД.
   Свежий backup/restore на копии обязателен перед0050; не подменять старую БД.
4. Собрать/проверить финальные native images и откат, выполнить обычный push
   staging и согласованный выпуск. Несколько API включать после ресурсного
   [preflight](multi-api-release-preflight-2026-11-03.md); строгий флаг сохранить.
5. Проверить опубликованные API/сайт/Mini, сессии/роли/админские входы,
   закрытые файлы, редакторы и режим оплаты. Без реальных списаний/писем.
