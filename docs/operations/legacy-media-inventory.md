# Адресная карта старых вложений

26 октября 2026. Инструмент `tooling/data/legacy-media-inventory.ts` работает только
с локальными метаданными: не подключается к БД/S3, не скачивает URL и не имеет
режимов изменения ACL, удаления или переноса. Инвентаризация не закрывает утечку.

## Вход и запуск

Экспортёр передаёт JSON следующего вида; в нём не должно быть текстов постов,
статей, паролей, почт или токенов пользователей:

```json
{
  "version": 1,
  "coverage": ["posts.photos", "articles.coverUrl"],
  "references": [
    {
      "kind": "postPhoto",
      "id": 938,
      "slot": "photos.0",
      "access": "restricted",
      "url": "https://s3.twcstorage.ru/daryadarcy-s3/feed/photos/example.jpg"
    }
  ]
}
```

Допустимые `kind`: postPhoto/postMedia/postPoster/commentPhoto/articleMedia/
publicReference. `access`: public/restricted/unpublished/unknown. Идентификаторы
положительные целые; тройка kind/id/slot уникальна. Неизвестные поля запрещены.
Размер входа ограничен 32 МиБ, число ссылок — 100 000.

```sh
pnpm exec tsx tooling/data/legacy-media-inventory.ts --input /private/metadata.json --output /private/new-report.json
```

Отчёт создаётся только новым файлом с правами 600; существующий файл, включая
исходник, не перезаписывается. В stdout только количества, без URL.
Секретные параметры URL и userinfo не попадают в отчёт: остаются отпечаток,
причина и ссылки на родительские записи. Сам экспорт метаданных тоже следует
хранить вне Git с правами 600. `coverage` — декларация экспортёра, инструмент
не доказывает полноту снимка и не проверяет наличие объектов или их ACL.

## Правила доступа при экспорте

- Опубликованный пост со статусом published и target=club — restricted.
  target=feed/both — public, согласно текущей серверной политике.
- Неопубликованные/отложенные записи — unpublished; отсутствующий родитель —
  unknown. Вложения и фотографии комментариев наследуют классификацию родителя.
  Это карта назначения материала, а не новая политика доступа к комментариям.
- Статья с access=club — restricted; её публичная обложка — publicReference.
- В карту включаются также текущие аватары, обложки видео и сезонные изображения.
  Скрытые видео сохраняются в карте, чтобы не повредить возможность отката.

`restricted-candidate` означает старую S3-ссылку без найденного публичного
использования в указанном покрытии. `shared-public` требует сохранить публичную
обложку и создать отдельную закрытую копию содержимого. `manual-review` включает
неизвестные/внешние/подписанные/неоднозначные URL. `protected-reference` означает
только форму API-ссылки: готовность привязки ещё не доказана.
Во всех группах `retirementAllowed=false`.

## Срез стенда

READ ONLY транзакция, 26 октября: 933 поста, 21 media, 2 статьи (69 строк
развёрнутых блоков), 7 аватарных записей, 82 видео, 1 набор настроек; комментариев
с фотографиями в этом срезе нет. Сохранены только идентификаторы и media URL.
Всего 4 945 ссылок, 4 943 группы:

| Классификация | Групп |
| --- | ---: |
| restricted-candidate | 384 |
| shared-public | 2 |
| public-only | 4 478 |
| unpublished-only | 11 |
| protected-reference | 5 |
| manual-review | 63 |

384 кандидата: 357 фотографий 183 клубных постов, 16 media и 11 файлов/изображений
статей. Наличие публичного доступа доказано отдельно для фото поста 938;
для остальных метаданные не заменяют сетевую проверку.
Фото постов **937 и 942** одновременно используются как публичные обложки статей
**5 и 6**. Их исходные объекты нельзя закрывать целиком без отдельной копии.
Внешние статические ссылки, история изменений/кеши/копии в чужих системах не
объявляются полностью покрытыми этим срезом.

сохранить. Этот запуск не выполнял ни одного из этих изменений.
