## Что сделать в панели Timeweb (скриншоты)

1. **VPS → daryadarcy-main → Обзор** — зона, тариф, IP  
2. **VPS → Бэкапы** — включено/выключено, расписание, число копий  
3. **MySQL → Charming Aquila → Резервное копирование** — физические/логические бэкапы  
4. **S3 → daryadarcy-s3 → регион** — ru-1 / SPB-3  

Сохранить скрины в `docs/roskomnadzor-screenshots/` (папку создать при получении).
