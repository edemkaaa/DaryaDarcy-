# Push-уведомления — сервисные и рекламные

Дата: август 2026

## Типы уведомлений

| Тип | Примеры | Согласие |
|-----|---------|----------|
| **Сервисные** | Подтверждение оплаты, продление/отмена подписки, системные сообщения | Не требуют отдельного маркетингового opt-in |
| **Рекламные / контентные** | Новые публикации клуба и ленты, новые PDF/товары, акции, скидки, приглашения возобновить подписку | Отдельное добровольное согласие, **выключено по умолчанию** |

Разрешение операционной системы (iOS/Android) на показ уведомлений **не считается** согласием на рекламные push.

## UI

В профиле (только native iOS/Android) переключатель:

> «Получать новости, новые публикации, акции и предложения DARYADARCY»

- По умолчанию **выключен**
- При включении — подтверждение с текстом согласия
- Можно отключить в любой момент, не затрагивая сервисные уведомления

## Backend

- `notifications.marketingConsent` — текущий статус
- `notifications.setMarketingConsent` — включить/отключить (журналируется)
- `sendMarketingPostNotification` — отправка только пользователям с активным marketing-согласием
- `admin.purgeUserPushData` — удаление push-токенов при удалении аккаунта

### Таблица `push_consent_events`

| Поле | Описание |
|------|----------|
| userId | ID пользователя |
| consentType | `service` \| `marketing` |
| status | `granted` \| `revoked` |
| consentVersion | Версия текста согласия (сейчас `2026-08-1`) |
| platform | `ios` \| `android` |
| createdAt | Дата и время предоставления или отзыва |

Миграция: `drizzle/0015_push_consent.sql`

## Маршрутизация (Expo / APNS / FCM)

**Важно для политики и Роскомнадзора:**

| Этап | Сервер | Юрисдикция |
|------|--------|------------|
| Backend Daryadarcy (Timeweb VPS) | `daryadarcy.com` | Россия |
| Expo Push API | `https://exp.host/--/api/v2/push/send` | США (Expo Inc.) |
| Apple Push Notification Service (iOS) | `api.push.apple.com` | США |
| Firebase Cloud Messaging (Android) | Google FCM | США / глобально |

**Вывод:** push-токены и содержимое уведомлений **передаются за пределы России** через Expo → APNS/FCM. Перед обновлением политики конфиденциальности и сведений для Роскомнадзора это необходимо отразить.

Expo Push используется как транспорт; Firebase SDK для аналитики **не подключён**.

## Ограничения содержимого push

В текст push **не включать**: ФИО, почтовые адреса, платёжные реквизиты и другие чувствительные данные. Только заголовок и короткий превью-текст поста.

## Критерии приёмки

- [x] Пользователь отдельно включает рекламные push
- [x] Пользователь отдельно отключает рекламные push
- [x] Сервисные и рекламные типы различаются на backend
- [x] Без активного marketing-согласия рекламный push не отправляется
- [x] Факт согласия и отзыва журналируется в `push_consent_events`
- [x] Admin API удаляет push-токены пользователя (`purgeUserPushData`)
