# Архив проекта

Материалы сохранены для истории. Они могут ссылаться на прежние ветки, серверы, команды npm, пути server/ и drizzle/ или возможности, которых нет в текущем коде. Не выполняйте их как актуальные инструкции.

## Что здесь

- [handover/](handover/) — прежние передачи проекта и снимки статуса.
- [design/](design/) — дизайнерские заметки и разборы референсов.
- [Старый продуктовый todo](product/todo-legacy.md) — исходный список, включая незавершённые пункты. Перенос в архив не означает их выполнения.
- [Старые известные проблемы](issues-2026-08.md) — состояние августа 2026, не текущий аудит.
- [Шаблон сервера](templates/backend-template.md) — документация исходного генератора, не руководство по этому бэкенду.
- [Старый npm lockfile](handover/package-lock.json) и [QR прежней сессии Expo](handover/expo-qr-code.png) — не текущие настройки/ссылка запуска.
- [Исторические исполняемые инструменты](../../tooling/legacy/README.md) — отдельно от документов, требуют проверки перед использованием.
- [Исторические PDF-аудиты](../audits/archive/) — находятся рядом с остальными аудитами.

Актуальные инструкции: [карта документации](../README.md). Текущая работа: [план](../../tasks/plan.md) и [чеклист](../../tasks/todo.md).

Архивные ссылки не входят в обязательную проверку актуальной документации: часть исходных внешних материалов и снимков больше не находится в репозитории. Эта страница проверяется как текущая навигация.
