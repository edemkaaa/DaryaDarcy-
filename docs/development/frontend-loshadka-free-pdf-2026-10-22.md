# Фронтендеру: вернуть бесплатное открытие PDF «Лошадка-качалка»

Дата: 22 октября 2026 года.
Статус: решение согласовано пользователем; реализация фронта этим документом не выполнена.

## Согласованное поведение

«Лошадка» остаётся бесплатной для всех: гостя, пользователя без подписки,
участницы клуба и администратора. Открывать исходную публичную ссылку:

**https://disk.yandex.ru/i/nDfsd5ptLO1xRA**

22 октября API Яндекс Диска подтвердил имя `МК Лошадка-качалка.pdf`,
тип `application/pdf`, размер 7 901 794 байта. Проверены метаданные;
полный файл и физический iPhone в рамках этой проверки не проверялись.
Это страница общего доступа к PDF, а не постоянный URL скачивания файла.
Не сохранять временный адрес скачивания вместо исходной ссылки.

Четыре зимние выкройки `holly`, `sock`, `star`, `apple` остаются клубными
и выдаются через существующий защищённый API. Ничего в их доступе не менять.

## Причина недоступности

В нашей предыдущей интеграции бесплатную «Лошадку» ошибочно направили в
клубный сценарий. Карточка требует подписку, а экран выкроек ждёт
`bindings.files.loshadka`. Такой файл в закрытую выдачу не переносили,
поэтому кнопка отключена. Исходный PDF не потерян.

Это не задача добавить пятый платный файл на бэкенде. Решение пользователя
заменяет прежнее «доступность Лошадки требует согласования» в документах
переноса и передачи по Библиотеке.

## Минимальные изменения фронта

### 1. Карточка в Библиотеке

Файл: `apps/frontend/src/features/library/library-screen.content.ts`.

Для элемента `id: "loshadka"`:

- `isClubOnly: false`;
- `action: "browser"`;
- `pdfUrl` — исходная ссылка выше;
- убрать `route: "/library/patterns"` у этой карточки.

Сохранить заголовок, обложку, пропорции и оформление. Использовать одну
константу ссылки для обоих мест открытия, без нового механизма загрузки.

`library-screen.tsx` уже умеет открывать `action: "browser"` через
`WebBrowser.openBrowserAsync`. `libraryMaterialKey("loshadka")` сейчас
возвращает `null`: не добавлять её в список закрытых материалов и не
перенаправлять в `LibraryFilesDialog`. Проверить результат с включённым
и выключенным клиентским флагом приватной Библиотеки.

### 2. Существующий блок «Лошадки» на экране выкроек

Файл: `apps/frontend/src/features/library/patterns-screen.tsx`.

- `handleOpenLoshadka` должен открывать ту же исходную ссылку через
  существующий `WebBrowser.openBrowserAsync`.
- Для обложки и кнопки «Открыть PDF» убрать зависимость от `hasClubAccess`
  и `bindings.files.loshadka`; они относятся к бесплатному материалу.
- Не показывать `PrivateLibraryState` для «Лошадки» из-за отсутствия
  приватной привязки. Ошибки и загрузку четырёх клубных файлов сохранить.
- Сейчас блок «Лошадки» вложен в ветку для участниц клуба. Вынести только
  этот существующий блок за условие подписки, сохранив его оформление
  и порядок относительно остальных блоков. Сам клубный gate не снимать.
- Обложка и кнопка должны работать также при ошибке запроса зимних выкроек.

Новые экраны, зависимости и редизайн не нужны. Не заменять общую обработку
всех выкроек публичными ссылками и не ослаблять валидацию закрытых файлов.

## Проверка перед передачей

- [ ] Гость и аккаунт без подписки: карточка «Лошадки» открывает исходный
  Яндекс PDF, без приглашения оплатить клуб.
- [ ] Участница клуба и администратор: открывается тот же бесплатный PDF.
- [ ] Прямой вход на `/library/patterns`: блок «Лошадки» доступен без подписки;
  работают и нажатие на обложку, и кнопка «Открыть PDF».
- [ ] При отсутствии `loshadka` в ответе API и при ошибке приватной выдачи
  бесплатная ссылка остаётся доступной. Нет вечного загрузчика и сообщения
  «Материал пока недоступен» для этого PDF.
- [ ] При выходе из аккаунта/смене аккаунта бесплатное открытие сохраняется;
  закрытые превью и файлы зимних выкроек не остаются доступными гостю.
- [ ] `holly/sock/star/apple` по-прежнему доступны admin/участнице с действующим
  доступом; гость и пользователь без подписки не получают закрытые файлы.
- [ ] Проверить открытие ссылки по нажатию в Safari на iPhone и обычном браузере;
  не подменять реальную проверку PDF одной проверкой нажатия.
- [ ] Прогнать применимые тесты, типы и сборку фронта; приложить результат.

## Границы

Бэкенд, рабочую БД, S3, старые файлы и их права не менять. Не импортировать
«Лошадку» в club-only API, не выключать защиту Библиотеки. Рецепты, Петербург,
бесплатный тест и остальные материалы не менять. Пуш и выкладка этим
документом не поручаются.

Агент подготовил только документ: исходники фронта и опубликованный стенд
в рамках этой задачи не изменены.
