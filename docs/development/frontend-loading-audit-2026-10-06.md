# Проверка скорости загрузки фронтенда — 6 октября 2026 года

## Что сравнивалось

Исходный сайт: [daryadarcy.dev.reeskeen.ru](https://daryadarcy.dev.reeskeen.ru/). Новая сборка: `fix/frontend-improvements, local production .next`. Chromium `152.0.7977.64`; время сохранения снимка — `2026-10-06T15:08:47.087Z`. Коммит удалённой сборки не подтверждён.

Это лабораторные замеры, а не PageSpeed score, INP или проверка физических устройств. Ниже сохранены параметры, сводка и все отдельные запуски, включая исключённые.

## Методика и ограничения

1. Сайт по ссылке: три холодных запуска каждого маршрута с настоящим публичным гостевым API; наблюдение 20 секунд.

2. Новая локальная сборка: три холодных запуска каждого маршрута и один повторный запуск с кешем, одинаковые гостевые тестовые ответы API; наблюдение 12 секунд. Это тестовая модель, а не снимок ответов сервера.

3. Авторизованные сессии не использовались. Бэкенд и БД не изменялись; service workers отключены.

4. Вес изображений сравнивается по запросам, начатым в первые 12 секунд. Используется Content-Length, где он известен, иначе проверенный исходный аудит. Это вес запрошенных файлов, а не уже переданные байты.

5. LCP записан в конце первоначального окна наблюдения, до прокрутки. LCP старого Клуба неполный: видимые изображения S3 не загрузились за 20 секунд.

6. Хостинг и поведение API различаются, поэтому весь выигрыш времени нельзя приписать фронтенд-правкам.

7. Первоначальные локальные замеры Клуба с экраном таймаута или остановившимся сервером исключены. Был также корректный запуск с настоящим API: LCP 2 348 мс, вес запрошенных изображений 3 976 448 байт.

8. Повторный заход может загрузить новые слайды вращающейся промокарусели, которых не было при первом заходе.

## Доступность исходного сайта во время проверки

Наблюдения относятся к конкретному окружению и времени; они не определяют виновный компонент инфраструктуры.

- Первоначальная навигация `/club` превысила таймаут 45 с; более поздний GET `/club` прошёл за 3 424 мс.

- Позднее `/api/auth/me` давал таймауты 10–20 с в Node, curl IPv4 и Chromium.

- Финальная проверка Главной завершилась таймаутом 15 с.

## Воспроизведение

Нужна готовая production-сборка. Скрипт допускает только GET/HEAD в proxy, не передаёт credentials и не изменяет удалённый сервис. `--start-current` запускает и завершает локальный фронтенд.

```sh
node tooling/operations/measure-frontend-loading.mjs --start-current
node tooling/operations/measure-frontend-loading.mjs --targets=current --api-mode=fixture --start-current --window=12000 --output=/tmp/daryadarcy-loading-local-controlled-2026-10-06
```

Первый вариант использует настоящий API, второй — явно обозначенную гостевую тестовую модель. `--api-mode=snapshot` или `--api-snapshot=...` позволяют сохранить и подставить настоящие публичные ответы, когда API доступен. Во время этой проверки записать свежий полный снимок API не удалось.
