### Профиль, I-01

`GET /api/auth/me` и публичная проекция текущего пользователя содержат
`profileRevision: number`. `profile.update` требует `expectedRevision` вместе
с изменяемыми полями. Ответ: `{success:true, profileRevision:number}`.

Версию захватываем при начале редактирования, сохраняем с pending input.
Нет версии в старом ответе: запись не отправляется, требуется обновить страницу.
Прежняя форма без expectedRevision отклоняется400, blind fallback отсутствует.
Успех с переданными полями увеличивает счётчик; пустой patch оставляет его прежним.
409 означает конфликт: не терять текст и не повторять автоматически. Перечитать
профиль и предложить явно сохранить сохранённый ввод на актуальной версии.
Чтение прежнего значения не доказывает завершение старого запроса, но CAS
запрещает этому запросу перезаписать уже подтверждённое новое сохранение.

Реализованы NameEditor, начальная анкета Клуба и общий hook; generated contract
обновлён. Версия отделена от sessionVersion. Поздний ACK или результат проверки с меньшей версией
не заменяет более свежий профиль того же аккаунта; версии разных аккаунтов
не сравниваются между собой. Internal name/gender writers и
upsert с явным name повышают счётчик. Отдельный receipt-протокол аватаров
сохраняется; квоты аватаров исключены владельцем. Цель этого CAS — сохранение
имени/пола из формы, не новый общий журнал upload-операций.

При будущем выпуске: свежий backup и проверка migration history, additive0045,
затем согласованный API+frontend. Возврат API к версии до0045 не требует
удалять колонку; не делать down-DDL и не менять пароли/сессии пользователей.

### Оплата, B-02 и F-01

Legacy `club.createCheckout` ограничен30вызовами/15мин на IP и5/15мин на
проверенный аккаунт до валидации/создания заказов. Каждый элемент tRPC batch
учитывается отдельно.429 возвращает Retry-After. Счётчики process-local:
при нескольких API workers нужна общая реализация, не новое обещание этого среза.
Новый guest/NORMAL receipt protocol и TEST-сценарий сохраняются.

При входе B и сохранённом guest intent для A теперь доступна явная оплата B.
Журнал A остаётся побайтно прежним, proof не раскрывается/не отправляется от B,
поздний ответ A не перенаправляет B. Об этой сохранённой чужой покупке показывается
нейтральное уведомление без адреса. Автоматической новой покупки нет.

Admin/moderator service access не привязан к окончанию их paid периода.
Сервер продолжает проверять доступ для каждого защищённого запроса.

### Аудио, I-02

Единый allowlist в packages/shared/src/audio-formats.ts подключён редактором
и сервером. Поддерживаются MP3, M4A/MP4 audio, WAV, OGG/Opus, WebM и FLAC.
