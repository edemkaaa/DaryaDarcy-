# Пояснения к коду и порядок в репозитории — 11 ноября 2026

## Итог и границы

После первоначальных заголовков выполнен дополнительный полный проход
рукописного кода. Прочитаны функции, обработчики, эффекты, тестовые сценарии,
helpers, инфраструктурные инструменты, архивные клиенты и стили. Пояснения
на русском описывают назначение, владение состоянием, побочные эффекты,
повторы, отказы и условия завершения. Очевидные поля/присваивания не
пересказываются отдельными комментариями; авторство старого кода не менялось.

В инвентаре **3 688 существующих файлов**. Из 1 966 файлов исходных форматов
**1 947 прошли полное ручное чтение**. Ещё 19 — явно перечисленные ниже
авторские данные и генерируемые типы/каталоги. Непокрытых рукописных файлов
этих форматов по итоговому сопоставлению инвентаря и журналов нет.

Это завершение документирования и организации, не закрытие всего аудита ошибок.
Автоматический [справочник файлов и блоков](file-guide/index.md) остаётся
навигацией и не считается самостоятельным доказательством ручного чтения.

## Изменения помимо комментариев и переносов

1. Генератор справочника теперь предпочитает содержательное пояснение архивного
   файла общей метке legacy. Добавлена регрессия; перед исправлением получен
   ожидаемый отказ теста.
2. Проверка документации охватывает README инфраструктуры и тестов. Новый тест
   сначала подтвердил пропуск битой ссылки, после исправления проходит.
3. Добавлена проверка канонических каталогов и существования Dockerfile от
   каждого build context. Область unit/MySQL и порядок SQL-suite сохранены.
4. Из архивного `_download-yadocs.mjs` убран вшитый временный доступ к Яндекс-
   документу. Теперь нужны закрытые `YANDEX_DISK_DOWNLOAD_TOKEN` и
   `YANDEX_DISK_RESOURCE_URL`; без них инструмент завершается до сети.
   История Git не переписывалась, действительность прежнего доступа не проверялась.

Последний пункт найден ручным проходом: прежняя шаблонная проверка секретов
не обнаружила этот формат. Её раннее утверждение о только синтетических
совпадениях нельзя считать доказательством отсутствия исторических секретов.
Значения доступа в документацию не перенесены.

Прикладные API, SQL, права доступа, дизайн, данные пользователей и флаги рабочего
окружения в этом этапе не менялись.

## Уборка и сохранность

В первоначальном проходе удалено только доказанно временное: три старых
`.tmp-prodamus-test-*`, 41 прежний Playwright result и один незавершённый Git pack
после проверки связности истории. Всего **45 файлов, 46,44 МиБ**.
Это прежняя уборка, а не дополнительное освобождение места в текущем переносе.

Исходники, SQL-история, медиа, ресурсы, базы, образы отката, backups и датированные
свидетельства сохранены. Неиспользуемый на вид файл не удалялся только по
отсутствию прямого import. Пустой прежний `__tests__` удалён после переноса всех
его файлов.
