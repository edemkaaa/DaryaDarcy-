## Документация и поддержка

Обновлены основной README, карта документации, запуск, workflow, архитектурное
описание API, README backend/frontend, инструментов, video-service и сборки.
Убраны устаревшие утверждения об основном Expo-клиенте и отсутствии жизненного
цикла фоновых задач. Датированные отчёты оставлены историческими снимками.
Исправления новых требований следует вносить в текущий план, а не задним числом
переписывать результаты прежних проверок.

`pnpm docs:files` обновляет девять страниц справочника. `pnpm check:files`
проверяет актуальность путей, номеров строк и описаний из исходников.
Проверка добавлена в GitHub Actions и сохранённый GitLab CI.
Генератор не выполняет исходники, не печатает тела функций и значения переменных.

## GitHub и границы публикации

Основной адрес: [edemkaaa/DaryaDarcy-](https://github.com/edemkaaa/DaryaDarcy-).
Репозиторий остаётся публичным по подтверждённому решению владельца, включая
имеющиеся тексты материалов и внутреннюю документацию. GitLab сохраняется
отдельным remote `gitlab`, история переносится без force-push.
Публикационные ветки — `staging` и `main`; начальный README GitHub сохраняется
в истории вместе с локальными коммитами.

Перенос подтверждён 11 ноября: обе удалённые ветки совпали со снимком `745ab481`,
сохранены 1 092 коммита вместе с объединением историй. Локальная рабочая ветка
`staging` подключена к `origin/staging`. Для кода этого снимка запущена
[проверка GitHub Actions](https://github.com/edemkaaa/DaryaDarcy-/actions/runs/43011278780);
на момент фиксации результата она выполняется. Следующий коммит отмечает только
проверенный факт публикации и не меняет исходники.

Перед отправкой проверены текущие текстовые файлы и достижимая история по
шаблонам токенов, приватных ключей, секретов интеграций и URL с паролями.
Найденные совпадения относятся к проверенным синтетическим тестовым фикстурам.
Рабочие секреты, дампы и игнорируемые операционные выгрузки не добавляются.
Проверка шаблонов не является доказательством отсутствия любой возможной тайны.

Соседний репозиторий Telegram-бота остаётся отдельным; его локальные комментарии
и README не смешиваются с деревом основного приложения.
Публикация исходников не означает выкладку, перенос БД или успешное прохождение CI.
