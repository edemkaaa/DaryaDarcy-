| **Smoke-тест** | `npm run smoke` |
| **Регрессия** | `npm run verify` |

**На сервере:**
- Фронт: `/var/www/daryadarcy/web-dist/`

- Nginx: `/etc/nginx/sites-available/daryadarcy` (шаблон: `deploy/nginx-daryadarcy.conf`)

## 4. Резервные копии

### 4.1 База данных (автоматические)

| Место | Путь | Retention |
|-------|------|-----------|
| **VPS локально** | `/var/www/daryadarcy/backups/*.sql.gz` | 14 дней |
| **S3** | `backups/mysql/*.sql.gz` | 90 дней |
| **Код бэкапа** | `server/_core/backup.ts` | mysqldump → gzip → S3, не чаще 1 раза / 24 ч |

**Последний бэкап на VPS:** `daryadarcy-2026-09-17T17-38-25-405Z.sql.gz` (~484 KB)

**Свежая копия для передачи:** `handover-2026-09-18/daryadarcy-db-latest.sql.gz`

### 4.2 Восстановление БД

```bash
# На VPS или локально с доступом к MySQL:
gunzip -c daryadarcy-db-latest.sql.gz | mysql -h HOST -u USER -p DATABASE_NAME
```

### 4.3 Изображения и медиа

| Тип | Где |
|-----|-----|
| **Основное хранилище** | S3 `daryadarcy-s3` — все фото ленты, аватары, обложки, shop assets |
| **Статика фронта** | `/var/www/daryadarcy/web-dist/` (шрифты, home/, assets/) |
| **Локальные ассеты** | `assets/` в репозитории |

S3 не имеет отдельного «полного дампа» — контент живёт в бакете постоянно. Для off-site копии: `aws s3 sync` с ключами из `.env`.

### 4.4 Web-dist бэкапы

На VPS **нет** истории web-dist (только SQL). Локальные копии — см. раздел 2.
