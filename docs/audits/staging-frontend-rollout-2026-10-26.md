## Сборка и исправление выпуска

Первый кандидат того же source был собран без отдельного compile-time флага
`NEXT_PUBLIC_VIDEO_THUMBNAILS_ENABLED=true`. API отдавал обложки, но клиент
не передавал `includeThumbnails:true` и показывал заглушки. Обнаружено в браузере.
Web возвращён на прежний образ без восстановления БД; выполнены новая сборка
с флагом, проверка кандидата с настоящим API и финальная выкладка указанного выше
image. Каталог после неё показал 20 → 22 карточки без заглушек отсутствующей обложки;
три видимых в конце изображения декодированы шириной 533 px.

Флаг обложек не входит в пять значений `required-server-files.config.env`:
проверка только этого списка недостаточна. Он должен явно передаваться в Next build.
Инструкция добавлена в [DevOps handoff](../operations/production-devops-handoff-2026-10-26.md).
Флаги TEST/VK/восстановления обычной оплаты/Библиотеки и лимиты сервисов сохранены.

Сборка выполнена с locked dependencies. Linux x64 SWC 16.4.1 проверен по npm-lock
integrity; native runtime подтвердил Next 16.4.1 и Sharp 0.35.5. При упаковке
временного runtime исключены только 2743 отладочных dependency `.map`; JS пакетов
не изменялся. Неудачные попытки сборки из-за места не считались проверками;
переключение выполнялось только после успешной проверки кандидата.
