# Проверка закрытых текстов в сборке, 2 ноября 2026

## Результат

На локальном коде `b0da6a58` закрыт ранее пропущенный production-тест
`tests/library-client-bundle.test.ts`. Свежая отдельная сборка Next прошла;
все 9 тестов этого файла прошли без пропусков.

- В `.next/static` и `.next/server/app` среди JS/HTML/RSC/TXT не обнаружены
  проверяемые платные тексты семи гидов эстетик (три вступления каждого гида).
  Проверка учитывает Unicode-экранирование в скомпилированном тексте.
- Ссылка на бесплатную «Лошадку» сохранена, две запрещённые старые ссылки
  выкроек в проверяемом содержимом отсутствуют.
- Семь результатов бесплатного теста совпали с сохранёнными контрольными хешами.
- Отдельная проверка клиентских сборок четырёх потребителей не обнаружила
  импортов backend-модулей и платных текстов; бесплатный сборник остаётся доступным.

Это проверка сборки обычного frontend при
`NEXT_PUBLIC_PRIVATE_LIBRARY_FILES_ENABLED=true`, не принятие текущего стенда
или отдельной Mini. Проверяются конкретные текстовые маркеры и известные ссылки,
а не отсутствие любого возможного закрытого содержимого во всех форматах.
SQL/S3-права, фактическое скачивание и внешние файлы здесь повторно не проверялись.

## Контроль чувствительности теста

В свою временную `.next/static` добавили файл с одним настоящим платным
вступлением. Production-тест ожидаемо упал на проверке утечки. Файл удалили,
тот же тест прошёл снова. В этих двух адресных прогонах остальные 8 тестов были
отфильтрованы намеренно; первоначальный полный прогон — 9/9 без skip.
Намеренная утечка существовала только в локальной временной копии, которая
не публиковалась и не обслуживала HTTP.

## Изоляция и доказательства

Сборка создана в собственной временной директории. Использованы установленные
зависимости, без установки пакетов и без копирования `.env`. У сборки отсутствует
рабочий API proxy; режимы оплаты выключены. Рабочий frontend/.next, БД, S3,
админские входы и сервер не менялись. Код приложения не изменялся; новые
зависимости, миграции, пуш и выкладка не нужны для этой проверки.

Временная копия и собственные процессы удалены. Лимит Node heap — 1536 МиБ;
пиковая оценка занятой памяти всего Mac через memory_pressure — около 8,93 ГБ
при защитном пороге 13,2 ГБ. Это не RSS контейнера или оценка боевой нагрузки.

Приватные воспроизводимые артефакты:
`../.local-artifacts/library-production-privacy-20261102/`:
`run.mjs`, `run.log`, `results.json`, `negative-control.json`,
`restored-control.json`, `verification.json`, `cleanup.json`.
Runner создаёт и удаляет только собственную временную копию.
