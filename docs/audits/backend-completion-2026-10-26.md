## Реализовано

1. Стандартное gzip/Brotli-сжатие разрешённых публичных JSON-ответов. Проверяется
   метод, точный список процедур, весь состав пакета, статус, тип, размер,
   Cookie/Authorization/Set-Cookie, private/no-store и Range. Закрытые данные и
   бинарная выдача исключены. Распакованный JSON побайтно равен исходному.
   Контракт фронтенда не изменён. Это транспортная оптимизация без изменения
   качества изображений; результат по времени загрузки требует отдельного замера
   после выпуска. [Контракт и границы](../development/public-response-compression.md).

   секретных URL, запрет перезаписи отчёта и прав изменений. Реальным loopback
   сервисом проверено, что ссылки инструмент не скачивает.
   [Формат и результат](../operations/legacy-media-inventory.md).
3. Получен новый READ ONLY срез медиа: 4 945 ссылок → 4 943 группы. Найдены

   закрывать целиком нельзя. Кандидат не означает доказанный публичный ACL.
   Подробные URL хранятся только в закрытом локальном отчёте вне Git.

## Что ещё реально требуется

- **Старые клубные источники.** Адресный перенос с проверкой качества/исходных
  байтов, резервированием и expected-old привязками, проверкой выдачи и только
  затем отзывом старых публичных адресов/кешей. Нельзя автоматически закрыть всю
  feed-папку или переносить старые фото через редактор с повторной потерей качества.
  Отдельно владелец отзывает два старых платных share Яндекс Диска; бесплатные
  материалы и публичные обложки сохраняются.
- **Боевая Prodamus-подписка.** Нет настроек владельца для 790 ₽/месяц и рекуррента.
  Требуется реальная приёмка оплаты/письма/входа/продления/отмены. TEST этого не
  доказывает. Одноразовую установку первого пароля нужно зафиксировать как
  согласованный вариант буквального условия договора о пароле в письме.
- **Настройки сезона.** Сейчас fixed winter; согласовать календарь/дату включения
  автоматической смены, чтобы текущая дата не неожиданно вернула autumn.
- **Внешняя приёмка.** Полный заказ из почтового клиента покупателя → менеджер,
  manager block UI, 22 VK-плеера и физические устройства/PWA/пилот. Не обходить
  ограничения проверочного браузера. 32/80 МиБ и 100 одновременных пользователей
  отложены пользователем, не объявлены закрытыми и не запускаются на заполненном
  рабочем сервере.
- **Совместимость и дополнительные операции.** Старые массивные read API остаются
  для известных вызывающих сторон до отдельного перехода; пагинация уже есть.
  Приёмка live Timeweb public-photo recovery после потери ответа/смены аккаунта
  остаётся отдельной. Автоматическая очистка старых/непривязанных объектов не
  включается и не подменяет безопасный перенос.
