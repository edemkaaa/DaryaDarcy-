| Малые фото повторно пережимались | Уже ограниченные JPEG/PNG/WebP до 1920 px и 4 МБ проходят без дополнительного canvas encode; EXIF/orientation/bytes проверяет и нормализует сервер. Большие фото сохраняют прежний ограниченный resize; их пик памяти не измерялся |
| Аватар терял качество до сервера | Crop остаётся 400×400, промежуточный результат — lossless PNG. Журнал сохраняет фактические MIME/расширение, JPEG v1 остаётся совместимым. В настоящем браузере синтетический crop → подготовка → локальный HTTP-upload → профиль прошёл; PNG 400×400, 4787 байт |
| Добавление фото меняло URL прежних фото комментария | Неизменённые File сохраняют blob URL; замена/удаление отзывает только свои URL, cleanup освобождает весь scope. Account/post-keyed thread сохранён; blob URL не пишутся в durable journal |
| Служебная проверка размеров постера не прекращала запрос | Public poster использует уменьшенную выдачу; getSize возвращает cancel и имеет срок 10 секунд. При source change/unmount запрос и callbacks освобождаются; старый portrait state сбрасывается |

Качество WebP на сервере осталось 85, серверные ограничения/удаление метаданных
не ослаблены. Сохранены прозрачность PNG/WebP и поворот JPEG по EXIF. Один
финальный lossy encode получается для подходящих малых источников и crop;
для больших исходников, требующих клиентского уменьшения, прежний resize остаётся.
Сравнение визуального качества всех реальных фотографий этим не заменяется.

В браузере Магазина при DPR2 три книги шириной 131 px выбрали готовые 320 px
варианты вместо прежних 900 px. Набор доступных вариантов не расширялся, старые
файлы не заменялись. Для карточек, у которых между 320 и 1200 нет промежуточного
варианта, браузер вправе выбрать больший файл ради плотности пикселей.
