# Передача проекта на аудит

Этот документ помогает собрать материалы и воспроизвести локальную проверку. Он не выдаёт разрешения на тестирование рабочего сервера и не подтверждает настройку production.

## Что передать

- Read-only доступ к согласованной ветке и точный commit, на котором проведена проверка.
- [README](../../README.md), [запуск](../development/getting-started.md) и [рабочий процесс](../development/workflow.md).
- [Обзор API](../architecture/api.md), [схему БД](../architecture/database.md) и [интеграции](../architecture/integrations.md).
- [Результаты этапов](README.md), [активный чеклист](../../tasks/todo.md) и замечания о пропущенных проверках.
- [SQL-миграции](../../packages/database/drizzle/) и [тесты контракта](../../tests/regression/trpc-contract.test.ts).

Не включать секреты, реальные учётные данные, дампы, приватные логи, node_modules, сборки и локальные служебные файлы. Тестовые аккаунты передаются отдельным защищённым способом, не через Git; [шаблон](templates/accounts.md).

## Как воспроизвести локальную проверку

Используйте отдельную тестовую MySQL backend_test. Команды из корня:

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm check:docs
pnpm check:boundaries
pnpm check
pnpm test
pnpm build
pnpm build:web
pnpm verify
```

Без BACKEND_TEST_DATABASE_URL интеграционные тесты БД пропускаются. В отчёте указывайте количество прошедших и пропущенных тестов, окружение и точный commit. Не представляйте локальную сборку как приёмку платежей, SMTP, устройств или защиту платных файлов.

## Границы проверки

Исследование исходников и изолированные локальные тесты — исходная безопасная область. Обращения к рабочим сервисам, вход в аккаунты, платежи, письма, импорты, изменение данных и деплой требуют явно согласованных целей и доступа. Документы в архиве такого согласования не заменяют.

Онлайн-оплата магазина и Web Push отключены, SMS и почтовое отделение закрыты по умолчанию. Состояние возможностей определяется [серверной политикой](../../apps/backend/src/launch/capabilities.ts), а не старым описанием функций.
