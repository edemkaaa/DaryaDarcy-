# CQ-3: сравнение и принятие ревизии статьи

2 ноября 2026. База `d72da377`. Работа локальная.

## Изменение

`compareArticle` и `acceptArticleRevision` перенесены из редактора в
`features/admin/article-revision-actions.ts`. Фабрика получает снимок текущих
полей, ссылки на attemptedEdit/uncertainSave, журнал, черновик, область операции
и callbacks редактора. Собственного состояния и нового жизненного цикла нет.
Функции создаются на каждом рендере, как прежде. Завершение записи создаётся
до передачи в фабрику; прежний отложенный вызов сохранён.

Сравнение перечитывает статью. При совпадении с отправленным вариантом подтверждает
завершение; иначе показывает серверный вариант, сохраняя ввод. Само сравнение
не повторяет запись.

Принятие проверяет серверную ревизию и незавершённую запись, требует подтверждения.
Для файловой операции сначала создаёт долговечный редактируемый черновик с теми
же File/receipt, затем освобождает журнал. Для обычного черновика сохраняет новую
базовую ревизию на устройстве. Запись на сервер требует отдельного сохранения.

AST тел обоих обработчиков совпадает с исходным: исключены только позиции и
форматирование, сохранены выражения, ветвления и значения строк. JSX, дизайн,
сообщения, API, проверки владельца и порядок await не менялись.
