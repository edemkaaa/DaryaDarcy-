# Архивный Expo-клиент Daryadarcy

Это сохранённый прежний клиент Expo / React Native с Expo Router. Он исключён
из активного pnpm workspace. Основной веб-клиент находится в
[apps/frontend](../frontend/); текущие команды из корня запускают Next.js.
Отдельно сохранён упрощённый [Vite-клиент](../legacy-web/).

## Где менять

- app/ — маршруты и экраны.
- components/ — компоненты интерфейса.
- hooks/ — клиентская логика и состояние.
- lib/ — клиент API и вспомогательные функции.
- assets/ — используемые приложением изображения, шрифты и другие ресурсы.
- app.config.ts — конфигурация Expo.
- [public/](public/) — прежние статические ресурсы Expo. Их присутствие не означает, что новый Next-клиент использует старый манифест.

Общие контракты находятся в [packages/shared](../../packages/shared/). Справочные тексты и заметки дизайна — в [docs/reference](../../docs/reference/), не среди исполняемых модулей.

## Статус команд

`pnpm dev:metro` сейчас является совместимым именем запуска основного frontend,
`pnpm build:web` собирает Next. Команд `android` и `ios` в корневом package.json
нет. Старую нативную сборку нельзя считать поддерживаемой только по наличию
`app.config.ts` или `eas.json`. Для её восстановления нужна отдельная проверка
версий, зависимостей и исходных мобильных интеграций.

Vite по-прежнему имеет явные команды `pnpm dev:web:vite` и
`pnpm build:web:vite`; результат помещается в `web-dist`. Его статический
каталог товаров, старые цены, YouTube, библиотечные ссылки и упрощённая сессия
сохранены как прежнее поведение. Эти файлы не являются требованиями текущего API.
`vite.config.ts` отделяет React и query chunks и проксирует `/api` только
в режиме локальной разработки. `index.html` монтирует старый `src/main.tsx`.
JSON-конфигурации сохраняются без комментариев, чтобы не менять их формат.

Для работы API запускайте pnpm dev:server или весь проект командой pnpm dev. Настройки и подготовка окружения — в [инструкции запуска](../../docs/development/getting-started.md).

Нативная сборка и реальное устройство требуют отдельной настройки среды. Успешная web-сборка не подтверждает работоспособность iOS/Android или доставку push.
