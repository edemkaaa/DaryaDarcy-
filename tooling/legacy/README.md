# Исторические инструменты

Здесь сохранены разовые пробы, миграторы прежней схемы, обработка отдельных ресурсов, SSH-эксперименты, исходный reset-project и генератор старого PDF-аудита.

Это архив исполняемых файлов, а не список рекомендованных команд. Некоторые файлы удаляют данные, меняют пароли, загружают файлы в S3, подключаются к прежним серверам или используют абсолютные Windows-пути. Не запускайте их для знакомства с проектом.

Содержимое сохранено для исследования; безопасность и совместимость этих операций не подтверждены. Перенос не отменяет эффект запуска. Старые миграторы не заменяют журнал SQL-миграций.

Если инструмент действительно нужен, сначала проверьте его входы, подключения, права, побочные эффекты и зависимости на изолированном окружении. Лишь затем согласуйте использование.
