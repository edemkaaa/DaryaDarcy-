# Прежние операционные помощники

Здесь остаются прежние миграторы, обработчики отдельных ресурсов и SSH-помощники. Деплой исключён из уборки: upload-deploy-tarball.mjs использует diag-tidb.mjs, SSH-настройка резервирования — _s3-bucket-size.mjs, а прежние SSH-сценарии загрузки обложек используют сохранённые загрузчики. Их файлы и ресурсы не удалены.

Это не список рекомендованных команд. Некоторые файлы удаляют данные, меняют схему БД, загружают файлы в S3, подключаются к прежним серверам или используют абсолютные Windows-пути. Не запускайте их для знакомства с проектом.

Разовые диагностические пробы, reset-project и генератор старого PDF-аудита удалены из рабочего дерева; история Git сохраняет их. Оставшиеся операции требуют отдельного ревью: перенос папок и уборка не подтверждают их безопасность. Старые миграторы не заменяют журнал SQL-миграций.

Если инструмент действительно нужен, сначала проверьте его входы, подключения, права, побочные эффекты и зависимости на изолированном окружении. Лишь затем согласуйте использование.
