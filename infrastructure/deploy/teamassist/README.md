# Запуск сервисов

Здесь находятся runtime-конфигурации: базовый `compose.yaml`, overlays,
Nginx edge и примеры ресурсов. Dockerfile и параметры сборки вынесены в
[../../build/](../../build/README.md).

Не объединяйте build-only Compose с runtime через `up`. Для нового окружения
сначала прочитайте [порядок сборки, выпуска и отката](../../build/README.md)
и [передачу DevOps](../../../docs/operations/production-devops-handoff-2026-10-26.md).
Публичные build flags компилируются в Next; runtime env не меняет готовый клиент.

`compose.yaml` не заменяет resolved-конфигурацию конкретного выпуска. Примеры
`compose.*.example.yaml` не применяются автоматически. Выбирайте overlays,
проверяйте итоговый `docker compose config`, образ, бюджет памяти/пулов и секреты
до запуска. Перенос файлов внутри Git не является разрешением пересоздавать
рабочие контейнеры, применять миграции или менять БД.
