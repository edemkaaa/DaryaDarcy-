Описания сборки не содержат рабочих секретов. Runtime env, дампы, ключи и
операционные выгрузки хранятся вне Git. Игнорируемые локальные архивы не являются
воспроизводимой сборкой и не должны использоваться как единственный backup.

Образы собираются из принятого коммита по [инструкции build](build/README.md).
Сам результат компиляции остаётся в стандартных игнорируемых каталогах:
`dist/`, `apps/frontend/.next/` и `web-dist/` для архивного Vite-клиента.
Эти каталоги не нужно коммитить или смешивать с конфигурацией развёртывания.

Изменение путей в репозитории не обновляет сервер. Датированные отчёты старого
стенда не подтверждают существование текущего хоста: по сообщению владельца
Beget удалён. Новый выпуск требует восстановления окружения и отдельной приёмки.
